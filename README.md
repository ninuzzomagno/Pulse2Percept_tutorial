# Intro
Hello everyone, I'm a biomedical engineering interested in neural engineering and visual prostheses. I discovered <b>pulse2percept</b> some years ago and I tested it in my free time. Nevertheless, I ran into some difficulties during my tests due to some aspects not covered in the official documentation, hence I got the idea to make these tutorials. 

For now, I'm using the last version of <b>pulse2percept (0.11.0)</b> and in these "lessons" we will need also other libraries as numpy, matplotlib, opencv and pytorch (maybe).

So, I will try to be the most methodical I can and, with this idea in my mind, I created a difficulty ordered list below. Every tutorial will have theory and, obviously, code. About theory, I don't have in mind to do neuroscience lessons but I will tell you all you need to understand the code so you can do your tests too.
